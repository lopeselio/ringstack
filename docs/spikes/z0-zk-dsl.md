# Z0: upstream's ZK program DSL

Track Z was planned around Go/gnark circuits copied from `zolana-examples/escrow-program`. Upstream has since moved ZK programs to a Rust DSL, so Z0 builds and runs the reference program on the new path instead.

## What upstream ships now

[`spr-program`](https://crates.io/crates/spr-program) 0.8.0 on crates.io is the SDK for Solana programs on the shielded pool. With the `circuit` and `client` features it is a ZK program framework:

- **One circuit, two runs.** A `circuit` fn is written once. Natively it builds the pool transaction's inputs and outputs on the client; as R1CS it constrains the same logic in the prover. Proofs are Groth16 over BN254 (arkworks 0.6).
- **Inputs are plain Rust.** `#[derive(ZkProgramCircuit)]` takes a struct with `private` and `public` fields; `#[derive(UtxoState)]` makes program state that lives in a UTXO's data. All public inputs are hashed into one public hash, so every circuit has one public input.
- **The program's proof and the pool's proof share `private_tx_hash`.** The program verifies its own proof (generated `Verifier`), then CPIs `transact` into the pool, which checks its own proof of the same transaction. Two proofs per transaction, bound together.
- **Builtins cover what we planned as gadgets.** `Uint<BITS>` has range checks, `assert_less_*`, `assert_in_range` and checked arithmetic; `Bool` has the logic; `Select`, `one_hot` and `select_index` index by a variable. `TokenUtxos` and `DataUtxo` handle UTXO hashing, ownership and conservation (`transfer`, `transfer_all`). `spr-zk-gadgets` adds Poseidon, hash chains and set membership (`is_in`, `assert_in`).
- **Tooling.** `zolana build-zk-program -p <crate>` (crate `spr-cli`) writes each circuit's `.r1cs`, test keys, and the verifier modules a program commits; `--check` fails CI when they drift. `check_constraints` reports the failing rule by name and source line, and `export_picus_r1cs` writes the circuit for the Picus under-constraint checker.

The reference program is `sdk-tests/timelock-escrow` in [helius-labs/zolana](https://github.com/helius-labs/zolana): lock funds in a UTXO owned by a per-creator PDA until a timestamp, then let only the creator withdraw.

## What ran

All at tag `rust-sdk-v0.8.0` (the commit the 0.8.0 crates were published from), on macOS arm64 with the repo's pinned Rust 1.98.1 and `cargo-build-sbf` 4.0.0. Go is not needed.

| Step | Command | Result |
|---|---|---|
| Circuit tests | `cargo test -p timelock-escrow-program --features circuits --test zk_functional --release` | Pass. Escrow then withdraw: native run, test setup, prove, and the program's verifier accepts; a changed `private_tx_hash`, an extra public transfer or a different viewing key are each rejected. 0.46 s after the build. |
| Program | `cargo build-sbf --manifest-path sdk-tests/timelock-escrow/program/Cargo.toml --features bpf-entrypoint` | Builds `timelock_escrow_program.so`, 88,304 bytes. |

| Localnet test | `cargo test --features localnet --test escrow` | Not run. It starts `zolana test-env --local`, which needs locally built prover and Photon binaries; 0.8 publishes neither (see [devnet](../devnet.md)). |

## What it means for Track Z

- **No `utxo`, `conservation` or `range` gadgets.** The DSL has them, constrained and tested upstream. Rebuilding them would only add risk.
- **A timelock is not a constraint.** Upstream binds the escrow's committed `unlock` to a public input in the circuit, and the program checks it against `Clock` onchain. The reusable piece is that pattern, helpers on both sides, not R1CS.
- **What is missing is the layer above:** M-of-N approvals bound to an approver set committed in the escrow terms, Merkle allowlist membership, and a template that wires circuits, program, verifier modules and client together. That is where Track Z now goes; see the [roadmap](../roadmap.md).
- **End-to-end runs go to devnet.** The program's proof is made locally; the pool's proof comes from Helius's prover, as for every other transaction in this repo. Deploying an 88 KB program to devnet locks about 0.45 SOL of rent (`solana rent`).
