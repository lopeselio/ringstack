# Running on devnet

Everything in this repo runs on Solana devnet against Helius Privacy (zolana **0.8**). Devnet is the only supported network: Helius Privacy is beta, its programs are under audit, and nothing here is fit for real money.

## Setup

1. A Helius API key in the root `.env` (git-ignored):

   ```bash
   API_KEY=<your key>
   ```

2. A devnet keypair holding SOL to pay for test wallets (the devnet RPC faucet is closed; use https://faucet.solana.com). Point `ZOLANA_FUNDER_KEYPAIR` at it.

3. Run any suite with `ZOLANA_NETWORK=devnet`:

   ```bash
   export ZOLANA_NETWORK=devnet ZOLANA_FUNDER_KEYPAIR=.devnet/funder.json
   pnpm --filter @ringstack/core e2e        # smoke, receipts, memos, wallet session, RingPay
   pnpm --filter @ringstack/ringd e2e       # events, signed webhooks, auto-merge
   pnpm --filter @ringstack/payroll e2e     # batches, resume, audit bundle, per-payee proof
   ```

CI runs the same three suites nightly and on demand (`.github/workflows/devnet.yml`), with secrets `API_KEY` and `DEVNET_FUNDER_KEYPAIR`.

## How the client reaches devnet

- **One URL.** `clientConfig({ network: "devnet", apiKey })` gives the SDK `https://devnet.helius-rpc.com/?api-key=…`. The SDK serves the indexer and the prover from the same host's `/v1/spr` namespace.
- **Attested prover.** Proofs are generated by Helius's prover in an AWS Nitro enclave. Every prover call is encrypted to an enclave that attests to `SignedTeePolicy.forNetwork("devnet")`: a policy file Helius publishes, signed by keys pinned in the SDK, re-downloaded as it ages and never used past expiry. The trust assumption is AWS Nitro plus Helius's policy signers: the prover sees your private inputs inside the enclave.
- **Verifier page.** The static verifier needs no API key. It reads devnet through the public Solana RPC and the Devnet-e Photon indexer.

## SDK 0.9 cutover (2026-11-06)

Devnet's indexer moved to the 0.9 API between the nightly run and the afternoon of 2026-11-06: tag and nullifier queries return a `Page` of `{context, data, paginationToken}` instead of `transactions` and `nextCursor`. `@heliuslabs/zolana@0.8.0-alpha` rejects that shape (`CLIENT_INVALID_RPC_RESPONSE`), so wallet sync failed with `WALLET_SYNC` everywhere. Upstream had warned that the indexer and SDK cut over together ([zolana#535](https://github.com/helius-labs/zolana/issues/535)). The repo moved to the renamed SDK, `@heliuslabs/spr@0.9.0-alpha`, the same day, and every suite below passed again on it, along with the [ZK template](../zk/template) e2e and a paid call to the live Azure demo.

## Results (2026-11-05, zolana 0.8.0-alpha; all re-run on spr 0.9.0-alpha 2026-11-06)

| Suite | Time | What it covered on devnet |
|---|---|---|
| core `smoke` | ~30 s | deposit → confidential transfer → decrypt change |
| core `receipt:e2e` | 16 s | issue, open and commitment-verify a receipt; tampered key, wrong signer, wrong transaction refused |
| core `memo:e2e` | 15 s | encrypted memo read by the recipient and shown on the receipt |
| core `session:e2e` | 162 s | register, enable merge, deposit, merge, transfer by Solana address, withdraw, and spending, merging and withdrawing memo payments |
| core `ringpay:e2e` | 49 s | `ringpay:` request paid with `payRequest`, verified receipt, merchant reads the order; four refusals move no funds |
| ringd `e2e` | 138 s | backfill, live memo events, restart without duplicates, `payment.sent` from read-only keys, signed webhooks with retry and failure, auto-merge paid by a separate fee payer |
| payroll `e2e` | 258 s | 17 payees in concurrent batches, crash and resume without double payment, expired-attempt retry, exact balances, audit bundle, per-payee proof that cannot open a co-worker's output |
| paywall-demo `e2e` | ~90 s | 402 challenge, private payment served, replay and cross-route refused, per-call/host/daily limits refuse without paying, vendor receives exactly the ledger total |
| agent-mcp `smoke` | ~60 s | MCP client over stdio: tools listed, balance, paid call, daily budget refusal, ledger |
| checkout demo | manual | order → private payment → ringd webhook → order marked paid, in the browser |
| verifier page | manual | devnet receipt opened with no API key; both outputs matched the chain |

A full pass of the three suites costs about **0.9 devnet SOL** (rent, fees and test deposits).

## Local stack

zolana 0.8 publishes no local-stack binaries (`zolana` CLI, prover); the published v0.6.0-alpha ones predate 0.8's attestation protocol and proving keys, so the SDK refuses their prover. `scripts/install-zolana.sh` and `scripts/localnet.sh` still install and start the v0.6.0-alpha stack, which **does not work with this repo's SDK 0.8**. A 0.8 local stack has to be built from source as [zolana-examples](https://github.com/helius-labs/zolana-examples) does (Rust, Go 1.27.3+, `cargo build-sbf`, zolana commit `6aba4a70`). Until Helius publishes 0.8 binaries, integration tests run on devnet.
